# 日历压力模拟

28 天、12 类人、5 代策略的日历调整压力测试。用于发现"灵活调整"运行一段时间后的二阶效应，不是真实用户预测。

## 运行

```bash
python calendar_stress.py   # 生成 out/runs.json、summary.json、summary.csv
python analyze.py           # 人群 × 策略表
python charts.py            # 三张图
python sensitivity.py       # 叠加折算 0.25 / 0.40 / 0.60
```

依赖：Python 3.10+，`charts.py` 需要 Pillow 和 Windows 字体 `msyh.ttc`；主模拟只用标准库。

## 五代策略

| 代号 | 含义 |
| --- | --- |
| P0 | 二元固定/可动，批量预览 |
| P1 | H0–H5 硬度光谱，H1/H2 先问 |
| P2 | + 最小代价函数与调整半径 |
| P3 | + 并行叠加（40% 折算） |
| P4 | 分级确认 + 改动预算 + 通知草稿 + 诚实失败 |

## 关键指标

目标达成率、冲突分钟、通知债、改动/天、确认/天、接受率、恢复天数、月末积压、叠加/月。定义见报告附录 B。

## 注意

- 参数是为对比而设的，不是实测值；40% 叠加折算、接受率、中断频率都会显著影响结果。
- 32 个随机种子只说明方向，不构成置信区间。
