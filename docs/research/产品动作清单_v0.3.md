## 2 八个模拟问题 → 八个产品动作

### A09 通知债徽标与草稿箱（N16）

**问题**：P0–P3 每月约 0.9 笔"改了但对方不知道"；只有 P4 清零。

**做什么**：

1. 任何涉及他人的改动（H1/H2），事件卡上出现"**对方未通知**"红色徽标；日历周视图顶部显示"欠 2 笔通知"。
2. 改动预览里直接生成通知草稿（微信/邮件），可编辑；提供"先发通知再改"和"改完提醒我发"两个选项。
3. 通知台账：谁、什么时候、哪个渠道、发没发；支持批量发送。
4. **永不自动发送**；发送前必须用户点；发送后记录时间。

**入口**：事件详情 / 改动预览 / 通知中心。
**规则**：H1/H2 且 `notify_required=true` 才产生债；H0 不自动改，只提示"需人工协商"。
**验收**：通知债 = 0；从改动到通知 < 24h；发送前确认率 100%。
**优先级/工作量**：P0 / S。

### A10 稳定模式与改动预算（N11）

**问题**：P4 改动 +6%，每天 4 次预算几乎从不触发；用户感觉日历一直在动。

**做什么**：

1. 日历头部显示"**本周已改 4 次 / 预算 6 次**"；超过 4 次变黄，超过 6 次变红。
2. 一键"**稳定到周末**"：非紧急改动只提示不自动应用；H0/H1 冲突仍可打断。
3. 改动前先给"**代价账单**"：动几件、影响几个目标、需要几次确认、欠几笔通知。
4. 超过预算后进入"**摘要模式**"：每天 18:00 一次汇总，不再逐条弹。
5. 改动日志按原因分类：新会议 / 会议延长 / 生病 / 用户手动 / 外部日历。

**入口**：日历头部状态条 / 设置 / 改动预览。
**规则**：预算按周重置；"稳定模式"期间只允许 H0 冲突和用户主动操作破例。
**验收**：改动 ≤ 5 次/周；撤销率 < 15%；稳定模式周使用率 > 20%。
**优先级/工作量**：P0 / M。

### A11 计划债务台账（N12）

**问题**：月末积压约 400 分钟，五代策略无差别；债务不可见，越滚越大。

**做什么**：

1. 侧边栏"**待补 3 项 · 4.5h**"常驻；点开是台账：来源、账龄、截止风险、原计划时长。
2. 债务上限：超过 8h 或 5 项变红，**暂停自动排新任务**，先做分诊。
3. 每周债务复盘：每项三选一——重排 / 缩短 / 放弃；放弃要记理由，**不扣目标**。
4. "**这周就到这里**"仪式：周五确认后，把低优先级旧债归档，不进入下周。
5. 计划时显示"本周剩余可承诺 2h"，避免把新任务排进已经透支的周。

**入口**：侧边栏"待补"Tab / 周五复盘卡。
**规则**：债务不计入目标；放弃是合法动作，不是失败。
**验收**：月末积压 < 200 分钟；债务账龄 < 7 天；主动放弃率 10–30%（健康区间）。
**优先级/工作量**：P0 / M。

### A12 打扰账本与确认预算（N13）

**问题**：确认 0.77–1.01 次/天，接受率只有 0.34；问得多不等于问得准。

**做什么**：

1. 每天最多 **2 次主动打断**；超出后进入摘要，不逐条问。
2. 三档确认：**静默 + 撤销**（低代价、当天、可逆）/ **Toast + 撤销**（中代价）/ **预览**（H0/H1、跨天、涉及截止）。
3. "**只问一次**"：用户拒绝后记录原因，不换说法再问；同一事件 24h 内不二次确认。
4. "**稍后决定**"队列：可延到晚上，24h 过期默认不动。
5. 每个确认必须写清"我在保护哪条约束"；写不出就不问。

**入口**：通知中心 / 设置 / 改动预览。
**规则**：打断预算按天重置；紧急（H0 冲突、当天开始）可破例一次。
**验收**：确认 ≤ 2 次/天；接受率 > 45%；"稍后决定"使用率 < 20%；静音率 < 10%。
**优先级/工作量**：P0 / M。

### A13 硬度体检（N14）

**问题**：P1 提问 +24%、目标只 +0.3pp；全标"必须去"等于没有可调空间。

**做什么**：

1. 每周硬度体检卡："你有 12 件事标了必须去，占 60%；可调空间不足。"
2. 当 H0/H1 占比 > 70%，显示"**全硬 = 不能调**"横幅，并预览后果：冲突会保留、目标可能缺口。
3. 降级建议：只对"过去 4 周从未缺席/从未改期"的事件提示"要不要降到'要商量'？"，**用户点才改**。
4. 每个硬事件可选一句"为什么硬"；AI 只引用，不复判。
5. 按事件类型给默认硬度模板（课/会/专注/习惯），减少逐条决策。

**入口**：硬度选择器 / 周报。
**规则**：AI 不自动降级；只给证据和建议。
**验收**：H0/H1 占比 < 50%；无解 < 1 次/月；硬度体检卡点击率 > 30%。
**优先级/工作量**：P1 / S。

### A14 并行折算校准（N15）

**问题**：叠加与目标损失 r=-0.55；40% 折算下叠得越多目标越低；高启动摩擦例外。

**做什么**：

1. **默认关闭**；只在三种情况建议：没有空位、块会整块丢失、用户主动点"挂一个任务"。
2. 挂载前显示区间："这节 90 分钟课，预计可产出 **30–45 分钟**；确认挂载？"
3. 课后校准："实际写了多少？"三选一（少于一半 / 一半 / 接近计划），更新这个人的汇率。
4. 认知负荷守卫：深度 + 深度禁止叠加；每天最多 1 次；会议/考试/面试默认不可叠加。
5. **不自动记产出**：未确认前按 0 计；确认后才计入目标。

**入口**：长按事件"挂一个任务" / 课后卡片。
**规则**：汇率按人 × 事件类型学；可查看、可重置；默认 0.4。
**验收**：叠加 ≤ 1 次/天；折算误差 < 20%；叠加后目标不下降；高启动摩擦人群可使用。
**优先级/工作量**：P1 / L。

### A15 恢复模式与最小可行周（N17）

**问题**：病一天后 5.6 天恢复；月末积压 400 分钟；所有策略都救不了。

**做什么**：

1. 一键"**今天不在状态 / 这周轻一点**"：暂停自动排程，标记恢复日。
2. 最小可行周：只保留 3 件必须做的事，其余顺延/缩短/放弃；显示"本周只保 3 件"。
3. 恢复期**不追债**：跳过的块进入"以后再说"，不自动排回本周，不扣目标。
4. 渐进恢复：第 1–3 天轻量，不新增建议；第 4 天再问"要不要恢复原计划"。
5. 回归卡："你休息了 2 天，本周还剩 3 件，要从哪件开始？"

**入口**：日历头部状态 / 设置 / 回归卡。
**规则**：恢复期只允许用户主动操作，AI 不主动提议；恢复模式可 1 天/3 天/本周。
**验收**：恢复天数 < 3；恢复后 7 天积压 < 150 分钟；恢复期主动建议 ≤ 1 次/天；回归完成率 > 70%。
**优先级/工作量**：P0 / M。

### A16 锁死审计与解锁建议（N18）

**问题**：无解 0.4–0.7 次/月；用户越焦虑越锁，越锁越排不下。

**做什么**：

1. 冲突面板直接说"**是哪 3 把锁挡住了**"：事件名、锁定范围、谁设的。
2. 解锁建议："把 1:1 从 H0 降到 H1，可释放 2 个候选时段"；附影响预览。
3. "**只这次放开**"：临时解锁一次，应用后自动恢复锁定。
4. 锁占比 > 50% 时提示"你的日历有 60% 不可动，AI 只能做冲突提示，不能重排"。
5. 保留"保留冲突"选项；**绝不静默移动锁定项**。

**入口**：冲突详情 / 周报 / 设置。
**规则**：解锁必须用户点；临时解锁只对一次变更有效；锁定变更写日志。
**验收**：无解 < 1 次/月；解锁建议接受率 > 30%；锁定被移动 = 0。
**优先级/工作量**：P1 / S。

## 5 验收指标与反指标

| 指标 | 目标 | 说明 |
| --- | --- | --- |
| 改动/周 | ≤ 5 | 超过进入稳定模式 |
| 确认/天 | ≤ 2 | 超过进入摘要 |
| 接受率 | > 45% | 低于 30% 说明问得不对 |
| 撤销率 | < 15% | 高说明改动质量差 |
| 通知债 | 0 | 涉及他人的改动必须有草稿 |
| 月末积压 | < 200 分钟 | 超过触发债务分诊 |
| 恢复天数 | < 3 | 病假后回到 80% 日目标 |
| 叠加/天 | ≤ 1 | 且只在手动开启时 |
| 无解/月 | < 1 | 超过做锁死审计 |

**反指标（出现一次就算失败）：**

- 移动了锁定事件；
- 静默写回未确认的变更；
- 替用户发送了通知；
- 未记录被当成 0；
- 自动修改截止日期；
- 恢复期主动增加建议；
- 叠加未确认就计入目标。
