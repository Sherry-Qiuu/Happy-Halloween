# 首次进入即画像

> 冷启动用户画像：一次目标输入、三张卡、一次校准

面向「目标 → 计划 → 执行 → 事实 → 反思」闭环　·　v1.1 精简版　·　2026 年 10 月 31 日


## 一、一页纸结论

用户第一次打开产品时，产品要做的第一件事就是**因人而异地给出第一版计划**。但四份交互设计已经立好规矩：不替用户判断目标、不静默推断、未知就是未知、AI 只呈现不评判。这份报告只回答一件事：在这四条里，怎么用最少的问题建立画像。

三个机制：**目标即入口**——首屏只问一句「这周你想推进什么」，画像从这句话长出来；**反向确认**——AI 的每个推断都摊开、标来源，用户改一次就永久改口；**行为校准**——行为只产出估计，带样本量、区间、有效期，永不写成事实。

- **3 张卡 / ≤60 秒**：首屏主动提问的上限，任何一张都能跳过
- **≤3 分钟**：从进入到看到第一版计划的目标时长
- **0 字段可进入**：画像完成度不是门槛
- **首周 ≤3 次**：自然节点上的追问预算

**明确不做**：注册墙、8 题问卷、性格测评、收入职业、用行为给用户贴「拖延」「自控力差」的标签。


## 二、前提：人看不清自己，画像该信谁

自评在三处系统性失真：时间估计普遍偏高（规划谬误）、节律判断只是叙事、完成率靠回忆。所以凡是「关于自己怎么做事」的问题，**声明只给初值，记录负责校准**。

但「只有客观载体能洞察人格」也跨了一步：载体只记录被设计的东西，没记录不等于没发生（文档 03 说「不回复即未知」，在数据层同样成立）；行为回答「什么」，不回答「为什么」；人格是从行为到解释的一次跳跃，不是一次观察。

> **立场**
> 接受它的方法论——证据优先、自述降权、多源交叉；拒绝它的结论——系统不能因此获得「定义用户是谁」的授权。**让记录负责事实，让用户负责意义。**

**表 1　四类对象，四种证据权威**

| 对象 | 例子 | 谁能提供 | 证据权威 | 缺失时 |
| --- | --- | --- | --- | --- |
| 约束 | 期限、可用时段、可投入量 | 声明 + 日历 / 记录 | 声明给初值，记录校验 | 未知，给保守默认 |
| 行为 | 何时做、做多久、中断几次 | 只有客观载体 | 记录优先，n≥3 才算模式 | 未知，不推断 |
| 意图 | 为什么做、什么算成功 | 只有本人 | 声明是唯一权威 | 未知，不替用户填 |
| 解释 | 「我拖延」还是「这周太忙」 | 本人 + 系统候选 | 用户选定后才生效 | 留作未解释的模式 |

冲突时不覆盖，生成一条**差异记录**（声明值 / 观察值 / 证据条数 / 时间窗）。差异不是错误，它既是校准入口，也是这个产品区别于普通待办的地方。

**表 2　六个步骤与时间预算**

| 步骤 | 做什么 | 时长 | 可跳过 |
| --- | --- | --- | --- |
| S0 首屏 | 一句话说出这周想推进的事，多模态输入 | 5 秒 | — |
| S1 目标草稿 | 建档 + 并行抽取候选字段 | 20 秒 | 可不等抽取 |
| S2 画像速写 | 三张卡：怎样算成 / 时间多硬 / 这周能分多少时间 | 60 秒 | 整组可跳 |
| S3 反向确认 | 逐条核对 AI 的理解，标来源、改错的 | 15 秒 | — |
| S4 交接排程 | 进入最小约束检查，生成第一版计划 | ≤3 分钟 | — |
| S5 首周追问 | 三个自然节点各问一句，同题 7 天不重问 | ≤3 次 | 拒绝即静默 30 天 |
| S6 校准 | 第 7 天，最多 3 条差异，用户判 | 1 分钟 | 可整屏跳过 |

三张卡只问这件事的约束，不问「你是什么样的人」。第三张特意写成「**这件事这周能分到多少时间**」而不是「你每周能投入多少」——前者是具体约束，可以当场核对；后者是自我评价，按上一章的说法不可信。

> 你的目标：3 周内通过科目二　　期限 11 月 21 日（你说）｜类型 技能考核（我推测）｜每周投入 5–10 小时（你选的）｜成功标准 还没有｜方便时段 还不知道

回访用户会多一行「记录」，与「你说」并列，不合并、不覆盖。

![图 2　校准会话：把「记录里的你」和「你说的你」并排，结论留给用户](report_assets/fig3-calibration.png)

*图 2　校准会话：把「记录里的你」和「你说的你」并排，结论留给用户*

- 每条差异都能点回原始事件；三个选项「是我 / 只是这周 / 以后别再提」，第三个必须存在。
- 每个模式假设带失效条件：「如果接下来 3 次晚间都完成，就撤回这条。」


## 四、画像怎么存

每个字段五元组：**值、来源、置信度（含样本量）、有效期、可见性**，缺一不入库。来源只有五类：你说、确认过的推断、记录、我算的、系统默认——最后一类只在本次会话生效。

字段按三层管：会话层不跨会话；目标层随目标归档；稳定层要两个目标都一致才升级。状态走 **未知 → 候选（抽取或 n≥3 的模式）→ 已确认（用户确认）→ 已过期 / 已删除**。

画像只记「怎么协作」，记忆才记「发生了什么」；分表、分 TTL 删除。不分开，三个月后画像会膨胀成 60 条判断，用户第一反应是「你凭什么」。


## 五、推断与校准

**表 3　从一句话到候选字段**

| 步骤 | 做什么 | 失败时 |
| --- | --- | --- |
| normalize | 语音转写、语言与时区识别 | 保留原文并标注「未转写」 |
| extract | LLM 结构化输出，每个字段必须带 quote | 无 quote 的字段直接丢弃 |
| ground | quote 必须能在原文精确匹配 | 匹配失败 → 整条丢弃 |
| verify | 二次判定「这句话是否支持该取值」 | ambiguous → 降为提问候选 |
| band | 按规则映射置信度档位 | 无法映射 → 不入库 |

四档置信度：高（原话直述）、中（单句可推出）、低（需跨句补全，只做提问素材）、禁止（人格、能力、健康、身份——不生成、不入日志）。这份禁推断清单要同时写进 prompt、服务端白名单和评测集；只写在一处，迟早会越界。

**表 4　客观载体：能看见什么，看不见什么**

| 载体 | 看得到 | 看不到 |
| --- | --- | --- |
| 日历 free/busy | 会议、忙碌块 | 会议之外的时间 |
| 任务完成记录 | 起止时间、是否完成、是否改期 | 为什么没做 |
| 编辑与预览 | 改了几处、改多久、是否放弃 | 改的原因 |
| 反馈时延 / 修订史 | 反馈间隔、改目标与减范围的时刻 | 动机变化 |

差异上界面的门槛三条同时成立：样本 ≥3；差异超过噪声（时长 >25%、时段跨 2 档）；窗口内无重大外部事件。任一条不成立，只更新内部权重，不打扰用户。


## 六、指标与验收

北极星：**首周「计划被接受且至少产生 1 次执行反馈」的用户占比**。不是画像完成率——用户不关心画像，只关心计划能不能用。

**表 5　漏斗与健康区间（首版假设，需实测校准）**

| 阶段 | 指标 | 目标 |
| --- | --- | --- |
| 进入 → 输入目标 | 提交率 | ≥55% |
| 输入 → 看到计划 | TTFT P50 | ≤2 分钟 |
| 看到 → 接受 | 首计划接受率 | ≥55% |
| 接受 → 反馈 | 24h 反馈率 / 7 日回访 | ≥40% / ≥35% |

- 画像质量：字段修正率 <15%；候选采纳率 60–80%；未知字段占比 20–40%（长期接近 0，说明系统在假装知道）。
- 校准质量：声明与观察的一致率分维度看；差异采纳率 40–60%（太高说明措辞太强，太低说明观察不准）。

实验分三组：A 8 题问卷、B 目标 + 3 卡（推荐）、C 目标 + 0 卡全 JIT。主指标为首计划接受率，非劣效界值 5 个百分点，每组约 220 人。若 C 不劣于 A 且 TTFT 更短，下一版直接砍卡片。


## 七、落地

**表 6　P0：4–6 小时可演示**

| 模块 | 做法 | 工时 |

**表 7　90 秒演示脚本**

| 时间 | 画面 | 台词 |
| --- | --- | --- |
| 0–10s | 首屏，只有一个输入框 | 第一次打开，我们只问一句话。 |
| 10–25s | 输入「3 周内通过科目二」，抽取浮现 | 这句话里已经有期限和领域，我只标不确定的部分。 |
| 25–45s | 三张卡快速点选，第三张跳过 | 三个问题，全部可以跳过。 |
| 45–60s | 反向确认，改掉「技能考核」 | 它记住的是我改的，不是我猜的。 |
| 60–75s | 生成周计划，复用日历 demo | 到这一刻才第一次生成计划。 |
| 75–90s | 弹出一条差异：你说 45 分钟，记录 28 分钟 | 这条是它观察的；我可以说是、说只是这周，或让它别再提。 |

上线前要拍板五件事：画像完成度**不**解锁计划；行为观察默认开但只用于默认值与差异提示，关闭不降级；首周追问 ≤3 次；稳定画像需两个目标一致；画像归用户，可导出、可删除。

## 八、风险

**表 8　四个主要风险**

| 风险 | 缓解 |
| --- | --- |
| 画像变问卷 | 3 张卡硬上限；全跳过路径；卡片可折叠 |
| 推断越界 | prompt + 服务端白名单 + 评测集红线，三道同时 |
| 假精确 | 估计必须带区间、样本量、到期时间 |
| 客观载体崇拜 | 缺席即未知；每条观察可展开；假设带失效条件 |

一句话收尾：画像不是我们偷看用户的档案，而是一份**可以当场核对、随时撤销的协作说明书**。
