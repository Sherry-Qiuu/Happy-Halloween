## 证据强度（重要）

这三类材料的可信度不一样，报告里也各自标注了，不要混着引用：

| 材料 | 方法 | 能说明 | 不能说明 |
| --- | --- | --- | --- |
| 需求全景 v0.1 | **模拟**用户研究：48 个虚构用户写变化日记，人工归并 | 需求面是否穷尽、用户会怎么追问 | 真实用户占比、真实付费意愿 |
| 压力模拟 v0.2 | **代理仿真**：12 类人 × 5 代策略 × 32 个随机种子 | 长期运行会把代价挪到哪里 | 真实人群参数；32 个种子只给方向，不构成置信区间 |
| 重排基准（`out_benchmark.json`） | **合成场景**：12 场景 × 80 次中断 = 960 次提案 | 策略之间谁更好、慢不慢 | 真实日历数据；数值不是对用户的承诺 |

结论都写成「在什么条件下成立」，代码里也只承诺这部分：例如策略只能动排布参数，改不了任务与目标。

## 复现

压力模拟只用标准库（画图另需 Pillow）：

```bash
cd docs/research
python sim/calendar_stress.py   # 12 类人 × 5 代策略 × 32 种子
python sim/analyze.py           # 人群 × 策略表
python sim/charts.py            # 三张图（需 Pillow + Windows 字体 msyh.ttc）
python sim/sensitivity.py       # 叠加折算 0.25 / 0.40 / 0.60
```

产物在 `sim/out/`：`runs.json`（原始逐次运行，未随仓库发布，重跑生成）、`summary.json`、`summary.csv`、`persona_summary.csv`，以及三张图。报告正文引用这些图时用的就是这些文件名。

重排基准：

```bash
cd calendar-rescheduler/backend
python evaluate.py              # 960 次提案 × 通用 / 画像两套权重
python breathing_eval.py        # 有 / 无呼吸层各 720 次
```
